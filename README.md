Лабораторная работа №1, вариант 19

Родительский процесс parent создает два дочерних процесса child1 И child2
Пользователь передает три файла в качестве аргументов командной строки:
1) Входной файл, откуда читается текст
2) Файл для child1, куда ребенок будет писать результат
3) файл для child2, куда ребенок будет писать результат

Родитель читает строки из входного файла и фильтрует их:
1) С вероятностью 80% строки попадают в pipe1
2) С вероятностью 20% строки попадают в pipe2

Дочерние удаляют из строк гласные и записывают результат в свой выходной файл

Родительские процесс и дочерний процесс это две разные программы

Структура:
├── parent.c — родительский процесс
├── child.c — дочерний процесс
├── input.txt — пример входного файла (всего три теста) 
├── README.md — этот файл
└── 209_Levakov_Lab1.pdf — отчёт
